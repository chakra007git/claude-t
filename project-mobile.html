FitPulse — Фитнес-трекер

Мобильное приложение для отслеживания тренировок, питания и прогресса. Кроссплатформенное решение на React Native с синхронизацией через Firebase.

Клиент

FitPulse Health

Год

2024

Роль

Mobile-разработчик

Стек

React Native, Firebase

Задача

Создать удобный трекер здоровья для iOS и Android одновременно

Стартап FitPulse хотел выйти на рынок сразу на двух платформах с минимальным бюджетом. Нативная разработка обошлась бы вдвое дороже. Нужно было приложение с плавными анимациями, офлайн-режимом и интеграцией с Apple Health / Google Fit.

Решение

React Native с нативными модулями и Firebase backend

Выбрал React Native для единой кодовой базы с нативными мостами для датчиков здоровья. Firebase обеспечил аутентификацию, Firestore для хранения данных и Cloud Functions для push-уведомлений. Reanimated 3 для 60fps-анимаций.

Функционал

Ключевые возможности

♥

Трекер здоровья

Шаги, пульс, калории, сон — всё из Apple Health и Google Fit. Автоматическая синхронизация данных с носимых устройств.

★

Планы тренировок

200+ готовых программ для дома и зала. Конструктор собственных тренировок с таймерами, подходами и весами.

☕

Дневник питания

База из 500K+ продуктов. Сканер штрих-кодов, быстрый ввод, макро- и микронутриенты. Рекомендации по КБЖУ.

⚠

Напоминания

Push-уведомления о тренировках, приёмах пищи и воде. Мотивационные стрики и достижения для удержания привычки.

☁

Офлайн-режим

Полная работоспособность без интернета. Данные сохраняются локально и синхронизируются при подключении к сети.

♿

Социальные функции

Челленджи с друзьями, публичный профиль, лидерборды. Возможность делиться тренировками и достижениями.
