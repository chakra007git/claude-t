IntraNet — Корпоративный портал

Внутренний портал для компании на 500+ сотрудников: документооборот, задачи, база знаний и корпоративный мессенджер. Микросервисная архитектура на Vue.js и Python.

Клиент

TechCorp Group

Год

2024 — 2025

Роль

Tech Lead

Стек

Vue.js, Python, Docker

Задача

Объединить 7 разрозненных инструментов в единую экосистему

TechCorp использовала Jira, Confluence, Bitrix24, Google Docs, Slack, 1С и самописную CRM одновременно. Данные терялись между системами, onboarding нового сотрудника занимал 2 недели. Руководство хотело единый портал с SSO и централизованным управлением.

Решение

Модульный портал с микросервисной архитектурой и плагинами

Спроектировал микросервисную архитектуру: каждый модуль (задачи, документы, чат, HR) — отдельный сервис на Python/FastAPI. Frontend на Vue.js 3 с Pinia. Единый SSO через Keycloak, Docker Compose для оркестрации, PostgreSQL + MinIO для хранения.

Функционал

Ключевые возможности

☰

Kanban задачи

Доски задач с drag-and-drop, спринтами, метками и дедлайнами. Интеграция с Git: автопривязка коммитов к задачам.

✎

База знаний

Wiki с markdown-редактором, версионированием, деревом категорий. Полнотекстовый поиск по всем документам компании.

✉

Корп. мессенджер

Каналы, личные сообщения, треды, реакции. Обмен файлами до 100 МБ, интеграция с модулем задач — создание задачи из сообщения.

♿

HR-модуль

Оргструктура, профили сотрудников, заявки на отпуск, табель рабочего времени. Автоматический onboarding с чек-листами.

⚙

SSO и безопасность

Единый вход через Keycloak с поддержкой LDAP/AD. Двухфакторная аутентификация, ролевой доступ, audit log.

☁

API и интеграции

REST API для каждого модуля. Вебхуки для внешних систем. Плагины для 1С, Google Calendar, корпоративной почты.
